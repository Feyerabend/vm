# The first ten Fibonacci numbers (as in chapter 2).
# The stack holds a b n, where n counts down to zero.

PUSH 0              #  0  a
PUSH 1              #  2  b
PUSH 10             #  4  n
DUP JZ 22           #  6  loop: leave if n = 0
PUSH 1 SUB          #  9  a b n-1
ROT ROT             # 12  n a b
OVER PRINT          # 14  print a
SWAP OVER ADD       # 16  n b (a + b)
ROT                 # 19  b (a + b) n
JMP 6               # 20
HALT                # 22  end
